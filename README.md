# Полная инструкция по использованию спамера

## Подготовка

### 1. Установка Python
Установите Python с официального сайта python.org.

### 2. Установка нужных библиотек
Разархивируйте архив, который вы получили, откройте командную строку, перейдите в директорию проекта, введя команду `cd путь/к/папке` и введите:

pip install -r requirements.txt


### 3. Получение нужных данных

#### 3.1. Получение данных API
1. Переходим на сайт https://my.telegram.org/auth и входим в аккаунт
2. Нажимаем API Development Tools
3. Там достаточно заполнить только поля App title и Short name, остальное все можно оставить как есть
4. Копируем api_id, api_hash и вставляем их в соответствующие переменные в файле a.env

#### 3.2. Создание бота
1. Зайдите в бота @BotFather
2. Введите /newbot и создайте бота для подключения софта к нему
3. Он выдаст токен, который нужно вставить в переменную BOT_TOKEN в том же a.env

!!ID тех, кто имеют доступ к боту прописаны в admins.txt, в боте есть управление администраторами, но в крайнем случае вы можете отредактировать данный файл

## Запуск
Отлично! Наш софт готов к использованию. Для его запуска нужно запустить файл main.py. Это можно сделать:
- Через командную строку (команда `py main.py`)
- Через Python IDLE (открыть нужный файл, нажать Run->Run Module)
- Просто запустить через файловый менеджер

У вас откроется консоль, и пока она открыта - софт работает. Для экстренного прекращения его работы можно просто закрыть эту консоль.

> Рекомендуем поставить софт на дедик, vps или хост, для большего удобства в использовании.

## Ответы на вопросы и информация о решении возможных проблем

### 1. В каком формате вводить прокси?
```
тип:ip:port:username:password
```

**Важно:** Прокси не являются обязательными! Бот может работать и без прокси. Если прокси не настроены, бот будет работать напрямую через интернет-соединение.

### 2. Где взять telethon-сессии?
Например, их можно загрузить с любого аккаунта купленного на lolzteam market.

### 3. Как происходит переключение сессий и прокси?
Сессии и прокси переключаются после каждого цикла, что позволяет обеспечить максимальный срок жизни сессии.

### 4. Что происходит если сессия мертвая или на ней спамблок?
- Проверка происходит уже на этапе загрузки сессий, мертвые сразу удаляются
- Также проверка всех сессий происходит в начале каждой рассылки, мертвые удаляются
- В процессе спама мертвые сессии тоже детектятся и удаляются
- Сессии со спамблоком в процессе спама временно помечаются как непригодные и не используются

> К сожалению детектить спамблок не всегда получается. Если ты по логам видишь, что у определенной сессии ошибка при отправлении в абсолютно каждый из чатов (при условии что чаты корректны), то просто советую удалить эту сессию из папки sessions на некоторое время, как только закончится ее цикл. Или можно оставить ее, на спам остальных сессий это никак не повлияет.

### 5. Что происходит с некорректными прокси?
Прокси тоже постоянно проверяются и удаляются в случае, если они некорректны.

### 6. В чем проблема, если на каждом цикле пропускаются одни и те же чаты?
Значит что проблема именно в конкретных чатах, например:
- Запрет на сообщения всем кроме админа
- Платные сообщения
- Вступление по заявкам
- Блокировка конкретного аккаунта админом чата

Причин может быть много, рекомендую проверить чат самостоятельно.

## Новые возможности

### 7. Поддержка ID групп и ботов
Бот теперь поддерживает отправку сообщений по числовым ID:
- **Отрицательные ID** (например: `-1001234567890`) - для групп и каналов
- **Положительные ID** (например: `123456789`) - для пользователей и ботов

Это позволяет отправлять сообщения:
- В закрытые группы, где у аккаунта есть доступ
- В ботов (например, @PremiumBot, @SpamBot и другие)
- В приватные каналы

### 8. Форматы ввода чатов
Бот принимает следующие форматы:
- `@username` - публичные группы и каналы, а также пользователи/боты
- `https://t.me/username` - ссылки на группы
- `-1001234567890` - ID закрытых групп/каналов
- `123456789` - ID пользователей/ботов

### 9. Работа без прокси
Бот может работать без прокси, используя прямое интернет-соединение. Это полезно для:
- Тестирования функциональности
- Работы в странах без блокировок
- Экономии на прокси-серверах

### 10. Как узнать id пользователя, чата и т.д.?
Напишите в нашу техподдержку в Telegram: @creocast, чтобы узнать актуальные способы узнать id, если у вас не получается это сделать

### 11. Прикрепление файлов к сообщениям 📎
Теперь вы можете прикреплять медиа-файлы к вашим сообщениям! Поддерживаемые типы:
- **🖼️ Фото** (JPEG, PNG и др.)
- **🎥 Видео** (MP4, MOV и др.)
- **📄 Документы** (PDF, DOCX, ZIP и др.)
- **🎵 Аудио** (MP3, WAV и др.)
- **🎤 Голосовые сообщения** (OGG)
- **🎞️ GIF-анимации**
- **🎭 Стикеры**

#### Как использовать:
1. При создании рассылки, когда бот попросит ввести сообщение, просто **прикрепите файл** к сообщению
2. Вы можете добавить **текст (caption)** к файлу - он будет отправлен вместе с файлом
3. Бот автоматически определит тип файла и отправит его корректно
4. **✨ Рандомизация работает с медиа!** Все варианты рандомизации текста (|||, ---, ###) применяются к подписям медиа-файлов!

#### Примеры:
**Пример 1:** Фото с рандомизацией
- Отправьте фото с подписью: `Смотри это!|||Проверь!|||Новинка!`
- Каждый получатель получит **то же фото**, но с **разной подписью**: кто-то увидит "Смотри это!", кто-то "Проверь!", а кто-то "Новинка!"

**Пример 2:** Документ с рандомизацией
- Отправьте PDF-файл с текстом: `Важный документ|||Срочно посмотри|||Новый прайс`
- Файл будет один и тот же, но подпись к нему будет меняться для каждого получателя

**Пример 3:** Видео с рандомизацией
- Отправьте видео с текстом: `Обзор продукта---Новое видео---Смотри обязательно`
- Видео останется одинаковым, текст под ним будет разным

**Важно:** Файлы сохраняются в папку `media` и будут пересылаться всем получателям в рассылке."# kwkdnjawndjnajdnjawkd"
